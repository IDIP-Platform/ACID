# ACID Documentation

ACID is a Python package and notebook workflow for microscopy image processing,
image quality control, segmentation, and feature extraction.

The repository currently focuses on an image-analysis workflow for fixed
microscopy samples from a Dengue virus Cell Painting project. The workflow
extracts fields of view from Nikon ND2 files, prepares metadata, performs image
quality control, estimates and applies background correction, segments objects,
and extracts cellular features.

!!! note "Project status"
    ACID is an ongoing project. The documentation reflects the current
    repository state and preserves known uncertainties from the README where the
    workflow or schema is still being refined.
