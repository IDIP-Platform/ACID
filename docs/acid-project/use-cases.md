# How Researchers Are Leveraging ACID

ACID is being developed to support microscopy image-analysis workflows in
infectious-disease research. This page is reserved for short use-case stories,
testimonials, and examples of how researchers apply ACID in practice.

### Dengue Cell Painting Workflow

ACID is currently being applied to a Dengue virus microscopy workflow involving
fixed samples, Cell Painting-inspired staining, image quality control,
segmentation, and feature extraction.

Read the detailed workflow description in
[Dengue Cell Painting](dengue-cell-painting.md).
