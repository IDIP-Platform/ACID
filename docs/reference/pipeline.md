# Pipeline

Jobs of the Snakemake workflow (`workflow/Snakefile`): one job per raw
acquisition or field of view, whole-stage and merge jobs, the shared
selection and result-record rules, and the `python -m acid.pipeline` command
line. See [Snakemake pipeline](../workflows/snakemake.md).
