# File Naming

This page summarizes the README naming conventions for raw and processed files.

## Raw ND2 Files

The README describes raw ND2 files with this structure:

```text
{cell_line}_{virus}_{treatment}_{total_imaging_time}_{experimental_procedure}_{well}.nd2
```

These files are generated by the Nikon microscope acquisition workflow and are
used as pipeline input.

## Extracted Fields of View

Extracted fields of view are saved in the `fov` directory as OME-TIFF files:

```text
{cell_line}_{virus}_{treatment}_{total_imaging_time}_{experimental_procedure}_{well}_{experiment}_{scene}.ome.tif
```

The README uses the terms field of view and scene for the same concept: one
image position extracted from the raw ND2 file.

## Segmentation Files

Segmentation masks are saved in the `seg` directory. The README examples mirror
the field-of-view filename pattern:

```text
file1_field_of_view1.ome.tif
file1_field_of_view2.ome.tif
fileN_field_of_viewM.ome.tif
```

## Metadata Files

Metadata files are saved as CSV files under `metadata`:

```text
[date]_ACID_metadata_part[notebook_progressive_number].csv
```

## Measurement Files

Global measurement tables are saved at the output-data root:

```text
[date]_ACID_glob_measurements.csv
```

!!! note "Historical names"
    Some README analysis-step text still mentions `nef_translocation` in output
    filenames. That appears inherited from another project and should not be
    treated as the preferred ACID naming convention.
