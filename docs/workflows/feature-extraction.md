# Feature Extraction

The feature-extraction stage measures cell-level properties from fields of view
and segmentation masks.

## Image and Mask Preprocessing

The README describes the following preprocessing before measurement:

- move the image channel axis to the final position for compatibility with
  `skimage.measure.regionprops`
- remove cells that are too small or too large
- remove cells without nuclei
- remove nuclei without cells
- remove cells touching image edges
- force nuclei to be completely contained inside cell masks
- assign nuclei belonging to the same cell the same label
- remove pixels whose intensity equals the raw dtype minimum or maximum
- verify matching label values for cells and corresponding nuclei
- smooth individual image channels with a Gaussian kernel

## Cytosol Masks

The cytosol segmentation mask is generated by subtracting the filtered nucleus
mask from the filtered cell mask.

This preserves matching label values between cytosol regions and corresponding
nuclei.

## Measurements

The README describes the default measurements as:

- mean intensity
- maximum intensity
- minimum intensity
- area

Measurements are calculated per cell and collected in a global measurements
table.

## Saved Outputs

The workflow updates metadata with cytosol-mask information and saves the global
measurement table at the output-data root.
